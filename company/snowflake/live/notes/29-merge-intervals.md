## 29. 合并区间（B08 · LC 56）
**证据：** 职级未确认；实际两轮店面记录（Phone Screen，P0）
**本文件合同：**
- 输入 `vector<vector<int>>`，每个是闭区间 `[start, end]`，`start <= end`；输入不保证有序。
- 闭区间下 `[1,2]` 与 `[2,3]` 相交于点 2，合并为 `[1,3]`。
- 返回按 start 升序、两两不相交的区间；空输入返回空。
- `merge` 按值接收（拷贝后排序），不修改调用方数据。
- 附 `mergeHalfOpen`：半开区间 `[start, end)`，`[1,2)` 与 `[2,3)` 不重叠，不合并。

**先问面试官：**
- 端点是闭还是半开？端点相接（`[1,2]`、`[2,3]`）要不要合并？
- 输入是否已排序？能否原地修改输入？
- 是否可能有 `start > end` 的非法区间、空列表？
- 输出顺序是否必须按 start 升序？

**思路：** 按 start 排序后，任何能和当前结果末尾合并的区间一定紧跟在后面。维护不变量：`merged` 中区间两两不相交且按 start 升序；新区间若 `start <= merged.back().end` 就扩展末尾，否则另起一段。扩展时取 `max`，因为新区间可能完全被包含。

**复杂度：** `merge` / `mergeHalfOpen`：T O(n log n)（排序主导），S O(n)（拷贝 + 输出）；n 为区间数。

**Follow-up：**
- 半开区间（已实现：`mergeHalfOpen`）：只把比较从 `<=` 改成 `<`。
- 插入一个新区间到已合并的有序列表（LC 57）：线性扫描三段（左侧不相交、重叠合并、右侧不相交），O(n)。
- 流式不断加入区间：用 `std::map<start, end>`，每次 `lower_bound` 找邻居合并，O(log n) 摊还。
- 不要和"同时最多几个会议室"（LC 253，扫描线计数）混淆。

**易错点：**
- 扩展时写 `back()[1] = cur[1]`，被包含的区间（`[1,10],[2,3]`）会把末尾缩短。
- 忘记排序或按 end 排序。
- 用 `merged.back()` 前没判断 `merged.empty()`。
- 闭/半开用错比较符，相接区间结果错误。
