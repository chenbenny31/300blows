## 41. 正整数 +2 / ×2 / ⌊÷2⌋ 任意操作路径（B21 · 无直接 LC；397 仅弱原型）
**证据：** 职级未确认；平台 Phone Screen（P1）
**本文件合同：**
- 输入正整数 a、b（前提 `a, b >= 1`）；所有中间值必须 >= 1（不允许经过 0）。
- 返回任意一个合法序列，元素为 `"+2"`、`"*2"`、`"/2"`；不要求最短。测试通过回放验证，而不是比对固定序列。
- `a == b` 返回空序列。对正整数输入，路径总是存在（见思路），所以"不可达返回空"这个分支实际不会触发；空结果只表示 `a == b`。
- `findPath`（BFS）只搜 `[1, 2 * max(a, b) + 2]`，要求 max(a, b) 约 <= 1e7（内存 O(M)，且 `x * 2` 不溢出 int）；`findPath2`（构造法）对任意 long long 范围可用，输出长度 O(log a + b)。

**先问面试官：**
- 要任意一个合法序列，还是最短序列？（题面说任意，不要自行改成最短路）
- 中间值必须是正数吗？允许经过 0 吗？（允许的话 b = 0 也可达）
- a == b 返回空序列可以吗？不可达用什么表示？
- a、b 的上限多大？输出可能很长（b 很大时 O(b) 个 "+2"）能否接受？

**思路：** 构造法证明总是可达：反复 ⌊÷2⌋ 必然到 1（a >= 2 时 a / 2 >= 1），b 奇数则从 1 一路 +2，b 偶数则先 1 → 2 再 +2，每一段单调且全程 >= 1。这条路径上的值都在 `[1, max(a, b)]` 内，所以 BFS 把值域限制在 `[1, 2 * max(a, b) + 2]` 不会丢掉可达性；多出来的部分覆盖能被 ÷2 落到 b 的 2b、2b + 1（以及一步 +2 的余量），允许"先冲过 b 再减半"这类更短路径（如 1 → 17）。BFS 用 parent 数组记录来源和所用操作，从 b 回溯再反转。

**复杂度：**
- `findPath`：T O(M)，S O(M)，M = max(a, b)（值域大小 2M + 3，每个值出 3 条边）。
- `findPath2`：T O(log a + b)，S O(log a + b)，即输出长度；不要说成与 b 无关。

**Follow-up：**
- 构造法（已实现：`findPath2`）：值很大时 BFS 内存不够，构造法只需 O(1) 额外空间（不计输出）。
- 要求最短路径：BFS 本身就给出值域内的最短；但要证明 2M + 2 的上界对最短也够用不容易（a, b < 80 的穷举中与更大上界结果一致，但这不是证明），面试中说明这是假设。
- 允许经过 0 或负数：0 是吸收态（0 × 2 = 0，0 / 2 = 0），只能 +2 离开；负数时 C++ 的 `/` 向零取整而不是向下取整，要改用 floor 除法。
- 双向 BFS 或 A*：只在要求最短且值域很大时有意义。

**易错点：**
- 构造法写 `while (a > 0) a /= 2`，最后一步变成 0，违反"中间值为正"。
- BFS 不设上界（×2 无限增长），队列爆掉或 int 溢出。
- BFS 回溯时忘记 `std::reverse`，或用 `parent[a] = -1` 作根导致回溯循环条件与"未访问"标记冲突（本文件用 `parent[a] = a`）。
- 把空结果同时当作"a == b"和"不可达"，不说明合同；测试时 a == b 要单独断言为空。
