## 01. 障碍网格任意起点到终点的最短路（A07 · LC 1091 原型）
**证据：** 明确 NG 原帖（C09 两轮线上 tech screen 第一轮）+ Jobright NG 标签（J10351）；Phone Screen；P0

**本文件合同：**
- 矩形 0/1 网格，0 可走、1 是墙；start / target 坐标合法。
- 四方向，距离按**步数**（边数）计；start == target 返回 0。
- 起点或终点是墙、不可达、空网格 → -1。
- 不修改输入网格。
- `shortestPathCells` 返回一条最短路（含首尾格子），失败返回 `{}`。

**先问面试官：**
- 四方向还是八方向？八方向时斜着走能不能「切角」穿过两堵墙之间？
- 距离按步数还是按经过的格子数（LC 1091 按格子数，起点算 1）？
- 起点 / 终点在墙上、二者相同、不可达各返回什么？
- 只要距离，还是还要具体路径？
- 网格多大？会不会有空行？

**思路：** 每一步代价都是 1，BFS 按距离非递减的顺序出队，所以一个格子**第一次被发现**时的距离就是最短距离。`dist` 同时当 visited 用，入队时就标记，避免同一格子重复入队。路径追问：发现格子时记下它的父格子，到达终点后沿父指针倒着走回起点再反转。DFS 不保证最短，不能用。

**复杂度：** V = m·n 个格子，E ≤ 4V。
- `shortestPath`：T O(V+E) = O(m·n)，S O(m·n)。
- `shortestPathCells`：T O(m·n)，S O(m·n)（父指针 + 路径）。

**Follow-up：**
- 已实现 `shortestPathCells`：父指针，不要在队列里存整条路径（每个状态拷贝路径会变成 O(V²)）。
- 八方向：`dr/dc` 改成 8 个；按格子数计时起点距离设 1。
- 多个起点：所有起点距离 0 一起入队（multi-source BFS）。
- 不同代价：0/1 代价用 0-1 BFS（deque），任意非负代价用 Dijkstra。
- 最多消除 k 个障碍（额外练习，非原帖确认）：状态变成 `(r, c, remaining)`，visited 也要三维。
- 为什么 BFS 不用 DFS：口头说清「第一次到达即最短」只对等权图成立。

**易错点：**
- 出队时才标记 visited：同一格子被多次入队，结果仍对但可能超时。
- `dr/dc` 写反或列用了 `dr[d]`。
- 先访问 `grid[0]` 再判空；忘了检查起点 / 终点本身是墙。
- 路径追问里没有给起点设父指针，回溯循环停不下来或把起点漏掉。
