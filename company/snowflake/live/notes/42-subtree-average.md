## 42. 根值与全部子树平均值的平均（B23 · 无直接 LC；2265 sum/count 原型）
**证据：** 职级未确认；平台 Phone Screen（P1）
**本文件合同：**
- 每个节点的子树平均 = `sum / count`，C++ 整数除法（向零截断）；n 个平均值再求和后除以 n，同样截断。
- 返回 `root->val == 平均值的平均`；空树返回 false。
- sum 与平均值的累加都用 long long（节点值是 int，3 个 INT_MAX 相加就溢出）。
- 附 `rootEqualsAverageOfAveragesFloor`：两次都向下取整（floor），只在出现负数时与截断版结果不同。
- 递归深度 = 树高；链状树高度到 ~1e4 以上要改显式栈（本文件按树高可递归处理）。

**先问面试官：**
- "整数平均"是向零截断还是向下取整？节点值可能为负吗？（负数时两者不同）
- 第二次平均是对 n 个节点的平均值求平均（不是对整棵树求平均）？
- 空树返回什么？
- 节点值范围，求和会不会超过 int？

**思路：** 后序遍历让每个节点拿到左右子树的 `(sum, count)`，自己的 sum、count 是 O(1) 合并，顺手算出本子树的平均并累加到 `avgSum`、计数到 `nodes`。全部遍历完后 `avgSum / nodes` 就是平均值的平均，与根值比较。关键是不能偷懒成"根值 == 整棵树平均"：整棵树平均只是根那一个子树的平均，测试 chain 1-0-4 和 chain 2-4-0 正好是两个方向的反例。

**复杂度：** 两个方法都是 T O(n)，S O(h)；n 为节点数，h 为树高（递归栈）。

**Follow-up：**
- 向下取整（已实现：`rootEqualsAverageOfAveragesFloor`）：用 `floorDiv`，余数非零且被除数为负时商再减 1。
- 只统计"节点值等于自己子树平均"的个数（LC 2265）：同一个后序，把累加改成计数。
- 用精确有理数比较（不取整）：比较 `root->val * n == Σ(sum_i / count_i)` 需要通分，分母会爆；可以改成 double 并说明误差，或者保留取整合同。
- 树很深：改成显式栈的后序（存 `(node, visited)`），或者先求出节点顺序再逆序合并。

**易错点：**
- 把题目误读成 `root->val == 整棵树 sum / count`。
- sum 或 avgSum 用 int，大值时溢出。
- 默认 C++ `/` 就是"向下取整"：`-1 / 2 == 0`，不是 -1；先和面试官确认舍入方式。
- 空树时 `avgSum / nodes` 除以 0；要先判 `root == nullptr`。
