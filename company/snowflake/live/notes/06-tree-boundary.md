## 06. 二叉树的逆时针边界（A14 · LC 545）
**证据：** New Grad；平台标签；Phone Screen；P0。题库版本限定 full / complete / balanced；地里另一帖（C11）是边界节点值之和

**本文件合同：**
- 输出顺序：root → 左边界自上而下（不含叶子）→ 所有叶子从左到右 → 右边界自下而上（不含叶子）。
- 按 LC 545 的一般规则：左边界优先走左孩子，没有左孩子才走右孩子；root 没有左孩子就没有左边界（右边同理）。
- 每个节点只出现一次；单独一个 root 不算叶子。
- 空树返回 `{}`；`boundarySum` 返回 `long long`。

**先问面试官：**
- 是 full / complete / balanced 的树，还是任意形状？（任意形状才需要「左边没有就走右边」的规则）
- root 没有左子树时，左边界是空的吗？
- 一个既在左边界又是叶子的节点算在哪里？（只算一次，算叶子）
- 输出列表还是求和？值会不会溢出 int？

**思路：** 分三段走。左边界：从 `root->left` 一路往下，遇到叶子就停（叶子留给第二段）。叶子：前序 DFS 自然从左到右。右边界：从 `root->right` 一路往下收集，最后反转追加。只要三段各自不碰叶子、第二段不包括 root，就不会重复。题库版本是满的平衡二叉树，左边界就是一路左孩子，但写成一般规则也一样短。

**复杂度：** n = 节点数，h = 高度。
- `boundary`：T O(n)，S O(h) 递归栈 + O(n) 输出。
- `boundarySum`：T O(n)，S O(n)。

**Follow-up：**
- 已实现 `boundarySum`（C11 求和版本）：因为列表已经保证每个节点只出现一次，直接求和不会重复计数。
- 顺时针：先右边界自上而下，叶子从右到左，再左边界自下而上。
- 非常深的树：叶子收集改成显式栈（右孩子先压栈，保证左先出）。
- 只要求叶子或只要左视图：分别对应第二段和 LC 199 的变体。

**易错点：**
- 单节点树把 root 再当叶子输出一次。
- 左边界循环不在叶子处停，导致最左叶子出现两次。
- root 没有左孩子时把右子树的节点当成左边界（LC 545 示例 1：答案是 `[1,3,4,2]`）。
- 右边界忘记反转，或者右边界循环里优先走了左孩子。
