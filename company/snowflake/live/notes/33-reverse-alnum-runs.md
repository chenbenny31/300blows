## 33. 反转连续字母数字子串（B20 · 无直接 LC，原型 LC 344）
**证据：** 职级未确认；平台 Phone Screen（P0）
**本文件合同：**
- "字母数字" = ASCII `A-Z`、`a-z`、`0-9`，用显式范围判断，不用 `std::isalnum`（受 locale 影响，负 `char` 是 UB）。
- 其他任何字节（空格、标点、`_`、UTF-8 多字节的每个字节）都是分隔符，位置和顺序不变。
- 每个"最大"连续字母数字区间整体反转；区间之间互不影响。
- 主方法原地修改 `string&`；`reverseRuns2` 返回新串。空串原样返回。

**先问面试官：**
- 字母数字是只算 ASCII 还是 Unicode 字母？UTF-8 输入怎么处理？
- 原地修改还是返回新字符串？
- `_`、`'` 之类算不算单词字符？
- 例子确认：`"ab12-cd!"` → `"21ba-dc!"`（字母和数字在同一个区间里一起反转）。

**思路：** 扫描找每个区间 `[i, j)`：跳过分隔符，遇到字母数字后让 j 走到区间末尾，对 `[i, j)` 双指针交换，然后 `i = j`。每个字符最多被 i、j 各经过一次，交换总数 ≤ n/2，所以线性。分隔符从不被移动，天然保持位置。

**复杂度：** `reverseRuns`：T O(n)，S O(1)。`reverseRuns2`：T O(n)，S O(n)（输出 + 缓冲区）。

**Follow-up：**
- 返回新串版本（已实现：`reverseRuns2`）：缓冲当前区间，遇到分隔符时反向写出；别忘了结尾冲刷最后一段。
- 反转单词顺序而非单词内部（LC 151）：先整体反转，再逐段反转。
- Unicode：先按 code point（或 grapheme cluster）切分，再用 Unicode 字母属性判断；字节级反转会破坏多字节字符。
- 只反转字母、数字原地不动（LC 917 类）：双指针从两端向内，跳过非字母。

**易错点：**
- 把整个字符串反转，或者把分隔符也一起参与反转。
- 字符范围写错：`'Z'` 与 `'a'` 之间的 `[`、`` ` `` 等被误当字母；用 `isalnum` 在负 `char` 上 UB。
- 返回新串版本忘记在循环后冲刷最后一个区间（`"abc"` 变成空）。
- 内层 `while` 漏了 `j < n` 边界检查。
