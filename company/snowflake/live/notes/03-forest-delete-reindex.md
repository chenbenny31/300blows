## 03. 删除 parent 数组森林中的节点并重新编号（A02 · LC 1110 弱原型）
**证据：** New Grad；平台标签（J11189）；Phone Screen；P0

**本文件合同：**
- `parent[i] == i` 表示 i 是根；输入是合法森林（无环），x 在范围内。
- 删除 x：x 非根时，x 的直接孩子改挂到 `parent[x]`；x 是根时，x 的每个直接孩子各自成为根。
- 孙子及以下不动，只是编号随之改变。
- 删除后幸存节点**保持原相对顺序**，下标和所有 parent 值统一重新编号（大于 x 的下标减 1）。
- 题库原示例输出有误：`parent=[0,0,1,1,2]`、删除 1 的正确结果是 `[0,0,0,1]`（已作为第一个测试）。

**先问面试官：**
- 根用 `parent[i] == i` 还是 -1 表示？
- 删除根时孩子怎么办：各自成根，还是选一个孩子当新根？
- 删除后是否压缩数组、幸存节点是否保持原顺序？
- 只返回新的 parent 数组，还是还要返回 old → new 的映射？
- 是删一个节点还是一批节点？

**思路：** 先在**旧编号**里决定每个幸存节点的新父亲（如果原父亲是 x，就换成 x 的父亲，或者自己成根），再把旧编号映射到新编号。因为只删一个下标 x，映射就是「小于 x 不变，大于 x 减 1」；替换后的父亲不可能再是 x，所以映射总是有定义。`deleteNode2` 显式建 `newIndex` 数组，批量删除时直接推广。

**复杂度：** n = 节点数。
- `deleteNode`：T O(n)，S O(n)（输出）。
- `deleteNode2`：T O(n)，S O(n)。

**Follow-up：**
- 一次删除一批节点：父亲替换要沿着链往上跳到第一个未被删除的祖先（被删的根则自成根）；`newIndex` 用前缀计数。可以先按拓扑顺序（从根往下）求每个节点的「最近存活祖先」，避免重复跳。
- 不能压缩（下标要稳定）：直接返回替换父亲后的数组，x 位置标 -1。
- 要同时删整棵子树：那才是 LC 1110 的断开语义，和本题不同。

**易错点：**
- 先压缩数组再改父亲：旧编号和新编号混用，`parent[i]` 指向错误的节点。
- 忘了把**不是 x 孩子**的节点的 parent 也重新编号（`{1,1,0}` 删 0：节点 1 的 parent 也要从 1 变成 0）。
- x 是根时把孩子挂到 `parent[x]`（也就是 x 自己）。
- 用 `vector::erase` 边删边改，迭代器/下标错位。
